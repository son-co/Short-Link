# 🚀 Setup and Run Existing React Project with Yarn

## 🛠️ Prerequisites:
- **Node.js** (Version: `>=18`)
- **Yarn** (Check version with `yarn -v`)

---

### 1. **Clone the source code:**
```bash
git clone <repository_url>
cd <project_folder>
```

### 2. **Install packages:**
```bash
yarn install
```

### 3. **Configure environment variables (if needed):**
- Create a `.env` file based on the `.env.example` file.
- Update the necessary values in the `.env` file.

### 4. **Run the project:**
```bash
yarn dev
```

### 5. **Access the website:**
- Open your browser at: [http://localhost:8039](http://localhost:8039)

---

### 🔄 **Additional Useful Commands:**

- **Build the project for production:**
```bash
yarn build
```

- **Run the project in production mode:**
```bash
yarn start
```

- **Check and fix code automatically:**
```bash
yarn lint
```

- **Run tests (if available):**
```bash
yarn test
```

If you encounter any issues or need further assistance, feel free to ask!
